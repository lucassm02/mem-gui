About MemGUI

MemGUI is a powerful, intuitive desktop GUI client for Memcached with a search DSL, query history, SSH/SASL connections, dump import/export, encrypted local storage, and fast threaded search. Manage connections, switch between servers, and keep every key, stat, and connection in view.

Version 1.3.1 adds a custom search DSL with export filtering, query history, faster threaded key search, plus help and connection reactivation.

What is new in 1.3.1

Released 2026-01-27. Latest release highlights.

Added

  • Custom search DSL with extensions and export filtering.
  • Query history to quickly reuse recent searches.
  • Help button and connection reactivation flow.
  • Fallback language when a translation key is missing.
  • Key list UI refreshed for faster browsing.

Changed

  • Search language syntax updated for new DSL rules.
  • Key search now runs with threads for responsiveness.
  • Key search component streamlined for clarity.
  • Private key selection no longer filters by file.
  • Internal refactors removed ineffective overengineering.

Fixed

  • Translation typos corrected across locale files.

Key Features

Search DSL + Query History

Filter keys with ordering and limits, then reuse searches from history to move faster.

Export Filtering

Export only what you need by applying DSL filters before dumping data.

Threaded Key Search

Responsive, threaded searches keep large datasets snappy and interactive.

SSH + SASL Connections

Connect securely with SSH tunnels and SASL authentication when required.

Encrypted Storage

Protect local data and SSH secrets with storage encryption.

Dump Import/Export

Export dumps for backup and import data back into a server.

Bulk Key Cleanup

Remove all keys on the current server in one action, with clear confirmations.

Server Insights

Track key counts, uptime, memory usage, and cache metrics.

Multi-language UI

Use Portuguese (Brazil), English, and other locales with fallback language support.
